# typescript-coding-practice

My TypeScript and problem-solving practice repo (22 Nov 2026 to 5 Feb 2027): TypeScript from fundamentals to advanced, and interview-style problems organised by pattern.
Each problem folder has the solution, a test, and notes on the approach and time/space complexity.

## How to run

1. Install Node 26 LTS.
2. `npm install`
3. Copy `.env.example` to `.env` (no secrets needed yet).
4. Run a file: `npx tsx <folder>/<file>.ts`
